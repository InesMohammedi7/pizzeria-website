# Pizzeria Website

A modern showcase website for a local pizzeria, built with HTML, CSS, and JavaScript.

## Features
- Responsive design (works on mobile and desktop)
- Interactive menu 
- Contact form
- Clean and modern UI

## Technologies Used
- HTML5
- CSS3
- JavaScript
